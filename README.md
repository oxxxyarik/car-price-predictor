## Car Price Predictor

Проект по разработке модели машинного обучения для оценки рыночной стоимости подержанных автомобилей.

## О проекте

В рамках проекта разработана модель машинного обучения на основе алгоритма **CatBoostRegressor**, предназначенная для оценки стоимости автомобилей по их техническим характеристикам.

Модель обучена на датасете, содержащем более **1.29 млн** объявлений о продаже автомобилей с площадок **Auto.ru** и **Drom**. Для взаимодействия с моделью реализовано веб-приложение с использованием **Streamlit**.

## Используемые технологии

- Python 3.13
- CatBoost
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## Датасет

- Источник: Auto.ru (Kaggle)
- 1 294 757 записей
- 18 исходных признаков
- 723 009 записей после предварительной обработки

Датасет не включен в репозиторий из-за большого объема. Скачать его можно по ссылке:
